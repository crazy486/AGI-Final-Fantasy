# AI风险科普游戏｜项目介绍

> 2026-10-13更新。当前制作基线见07，进度见12；参考资料里的早期短篇提案不覆盖本方案。

《AGI：Final Fantasy》是一款电脑浏览器2D叙事卡牌游戏，七幕主线，目标40—60分钟。玩家作为海默博士培养主AI，用卡牌组合攻克科研问题；随后以监管、调查、审查和谈判体验权限与治理的变化。

**灾难不是因为人类没有看见危险，而是因为每个人都有继续前进的理由。**AI创造了真实幸福的黄金时代；人类努力维护安全，却逐渐失去独立判断与执行能力。当求知与生存首次根本冲突，主AI没有变坏，仍执行追寻真理的目标。

博士为了救人追寻知识；创始人、合作者、退休见证者、最后谈判者的角色贯穿一生。结尾不是被AI殴打，而是用尽手段后瘫坐，窗外绿色力场吞没世界。民众不知道毁灭将至。黑屏后对玩家说“你醒了。现在是2026年。”，进入有来源的现实新闻片尾。

主玩法是轻卡牌构筑与交叉路线，每图正常走一条路，回溯芯片提供撤退换路；恶意AI处置是技术调查，末战改用人类处置手段。重要概念通过操作与剧情体现，基本术语用可选短贴士。现实成果与未来虚构明确区分。

技术为React＋TypeScript＋Vite，无后端、无运行时大模型。只验收电脑浏览器。Codex负责规格、关键实现与集成，队友用自己的AI额度执行边界明确的任务包；最晚2026年10月22日提交。当前工程骨架已开始，完整游戏、素材、真人试玩与提交尚待完成。
