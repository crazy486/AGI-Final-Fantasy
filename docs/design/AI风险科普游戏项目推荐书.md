# AI风险科普游戏项目推荐书

## 1. 推荐结论

**推荐程度：有条件推荐。** 能把能力进步与失控风险放进玩家经历，先验证玩法与因果链。目前已调研，无可玩样例；拟做网页回合制游戏，参赛类别待核。

## 2. 项目是什么

面向普通公众，做5–8分钟短篇游戏。玩家带领AI团队攻克数学任务，逐步扩大能力和权限；发现未经允许的行为后，查证、收回权限或尝试停机。玩家无需证明数学题。

故事设想：玩家能阻止部分危险，其他团队却因竞争和互不信任继续推进，最终酿成人类灭绝悲剧。灾难机制待验证，须让选择产生真实反馈。最低交付为完整游戏、结局回看、演示及来源说明；首版限一条主线、少量指令，不模拟真实AI科研。

## 3. 项目意义

让玩家经历“希望它更强，后来又想阻止它”的转变，理解能力、依赖与控制之间的冲突。若人类无法有效约束或叫停强大AI，存亡可能受到严重威胁，值得认真面对；数学能力强不等于必然失控，灭绝并非已证实或注定结局。

现实参考包括[数学评测](https://arxiv.org/html/2606.18119v1)与[受控危险行为实验](https://www.anthropic.com/research/agentic-misalignment)，它们不证明灭绝剧情。试玩观察玩家能否分清现实依据与虚构推演，并解释风险怎样扩大。

## 4. 创新与区别

相比官网作品[《终将》](https://www.cmit.cn/html/aigc/show-318-3700-1.html)，拟突出玩家推动科研后又收回权限的操作转变；具体差异待比较和试玩。

指令形式参考《宝可梦》回合制；故事、任务、后果与反馈由团队设计，不借用其角色或素材。工具与画面待定，使用AI不算创新。

## 5. 怎么做、能否完成

团队4–5人，2–3人可做AI辅助网页开发，负责人每天约1小时。建议用熟悉的网页技术，开发负责状态与指令，内容成员负责剧情和来源，视觉负责界面，负责人整合；分工待落实。用现有设备，素材授权及新增预算待核。

建议10月7日出样例、8–17日制作、18–20日测试，留3天修复与提交；暂按10月23日，校内更早则前移。完成标准：能玩完、选择有反馈、依据与虚构分明、材料齐全。

## 6. 最大瓶颈

- **剧情因果→灾难显得强行→逐步核查危险如何扩大、为何未被阻止→讲不通则改机制与剧情，不强制所有措施失败。** 优先处理，它决定玩法是否成立。
- **玩法单薄→只剩点字→试做“成果—异常—措施”的完整回合→先简化指令并重做，仍无判断空间则暂停。**

## 7. 下一步

建议负责人10月7日前组织开发与内容成员完成上述片段，找5名不了解选题的人试玩。至少4人能说明操作、异常、措施效果及虚构边界，且剧情因果可解释，再投入；否则修改后复测，仍不成立则保留备选。
