# AGI：Final Fantasy 补充素材交付

按用户提供的《素材需求清单.md》制作，2026-10-16。共 **61 张图片 + 6 个音效 = 67 项运行素材**，含所有列出的 P0、P1、P2 和可选变体；“人类手段卡”表述为 8 张，但实际列出 9 个文件，本包全部提供。

- `src/assets/bg/`：9 张背景，1920×1080 WebP，每张不超过 700KB。
- `src/assets/portraits/`：10 张透明 PNG；问源两张 1024×1024，人物 1024×1536。
- `src/assets/art/`：6 张剧情 CG（1920×1080 WebP）、11 张难题（512×512 透明 PNG）、25 张卡牌（480×320 PNG）。
- `src/assets/audio/`：6 个 OGG，44.1kHz 双声道；`masters/` 留存 WAV。悬停声和机房环境声明显比动作音效轻。
- `index.html`：离线预览，可点击图片放大、播放连续 CG、试听音效。解压后用浏览器打开。
- `manifest.json`：文件尺寸、透明像素检查、SHA256、音频参数和编码后真峰值；`sources/generated-index.json` 留存实际提示词及生成源路径。

## 接入

把包内 `src/assets/` 合入 Opus 版本对应目录；音效若工程使用其他目录，请按其资源加载约定移动。本包没有修改当前工作区游戏源码，也没有冒充已经完成 Opus 工程接入。程序仍需绑定对应背景、角色表情、敌人和卡牌 ID；第五幕交互命中区必须按最终 home.webp 的画面重新核对。

## 制作与检查边界

场景、CG、人物和难题插画使用内置 image_gen；风格与角色参考来自本项目既有 T05。问源为非人形抽象光环，角色均为虚构设计。卡牌采用原创简洁矢量图标，提供 SVG 源文件并渲染成规定 PNG。音效用原创数学合成，无第三方录音、采样或音色库。

通过文件可读性、像素规格、透明度、体积、音频解码和真峰值检查，并检查了素材缩略图及关键大图。生成式表情/光照编辑保留原角色和构图，但不保证非编辑区域逐像素相同；连续 CG 入游戏后仍需复核淡入效果。自动检查与素材预览不等于真人试玩或用户审美验收。

清单中的真实新闻核验不属于新素材生成，本次未生成新闻画面，也未修改片尾事实或来源。
