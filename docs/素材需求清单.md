# 《AGI：Final Fantasy》素材需求清单（交给生成模型）

已接入游戏：T05 的 6 张背景、7 张立绘、3 种卡框；T06 的 18 首配乐/演出音与 6 个音效。下面只列**还缺**的素材。

## 统一规格（所有图片都必须遵守）

- 画风：与现有 T05 素材一致——半写实日系插画，柔和自然光，克制的近未来科幻，色调偏冷蓝，干净不脏乱。生成时把 `T05/正式交付/originals/` 里的 `lab-day.png`、`haimer-calm.png` 作为风格参考图一并提供。
- **图中不能有任何文字、数字、Logo、水印**（文字由程序绘制）。
- 背景：1920×1080，WebP（≤700KB），画面下方 1/3 不放关键内容（对话框会盖住）。
- 立绘：1024×1536，透明背景 PNG，半身到膝，人物居中，与现有立绘同比例、同站位、同光照。
- 文件名按下表，放进 `src/assets/bg/`、`src/assets/portraits/` 或 `src/assets/art/`。

## 四、战斗插画（让卡牌战斗不再只是文字面板）

**敌人插画**：11 张，512×512 透明 PNG，统一成抽象的“难题具象化”（发光的几何结构、数据流），不要怪物、不要人脸。文件名 = 敌人 id：

| 文件名 | 敌人 | 意象 |
|---|---|---|
| arith.png | 算术应用题 | 漂浮的简单数字方块（无可读数字，用点阵代替） |
| geometry.png | 内切圆迷阵 | 三角形里套着发光内切圆，线条交错 |
| sortFort.png | 排序指令堡垒 | 高低不一的柱状方块堆成的小堡垒 |
| plasma.png | 失稳的等离子体 | 环形磁场里扭动的紫蓝等离子团 |
| capset.png | 禁止三点共线（小 Boss） | 网格上散布的发光点阵，几条红色禁止连线 |
| fluidCore.png | 湍流核心（Boss） | 巨大的漩涡状流体核心，深蓝白 |
| boundary.png | 边界条件 | 包裹漩涡外侧的一圈发光边框 |
| mesh.png | 自适应网格 | 疏密变化的三角网格面片 |
| matrix.png | 矩阵乘法壁垒 | 层层叠叠的半透明方阵墙 |
| protein.png | 折叠的蛋白质 | 彩色缎带状蛋白质折叠结构 |
| bootstrap.png | 自举工具链（Boss） | 自我缠绕、不断延伸的齿轮与电路，越往外越复杂 |

**卡牌插画**：15 张，480×320 PNG（放在卡框中间的插画区），扁平简洁图标风，冷色调。文件名 = 卡牌 id：advance（向前的箭头路径）、verify（对勾盾牌）、retrieve（书页与放大镜）、breakthrough（光束击碎墙）、decompose（一块拆成多块）、chain（相连的链环）、crossCheck（两条线交汇于一点）、counterexample（一个红点打破整齐队列）、codeRun（终端窗口与播放键）、testGate（闸门拦下一个红色方块）、measure（刻度表与重复的波形）、formalProof（层层堆叠的严密方块）、reuse（循环箭头与存储块）、multiAgent（三个小光点协同）、selfImprove（向上微微倾斜的阶梯）。另加 noise.png（灰色雪花噪点）。

**第七幕人类手段卡**：P2，同规格 8 张：freeze（冻结的锁链）、isolate（被切断的节点）、cut（损毁的提取站剪影）、evacuate（人群走向避难所）、shutdown（老式大红物理开关）、orbit（被干扰的卫星）、audit（翻开的厚卷宗）、appeal（广播信号波）、oldQuestion（2017 年旧终端屏幕的微光）。

## 五、音效（配乐已齐，只缺这些）

格式：OGG，44.1kHz 双声道，峰值低于 -1dBTP，响度与现有 play/hit/block 一致，原创或明确 CC0。

| 优先 | 文件名 | 用途 | 描述 |
|---|---|---|---|
| P0 | mechanic.ogg | 机制触发（“已验证”、推理链释放、子问题解决） | 0.3 秒，清脆的上行双音“叮—叮”，科技感 |
| P0 | lose.ogg | 战斗失败 | 1 秒，低沉下行三音，不刺耳 |
| P1 | cut.ogg | 第三幕切断连接、第七幕物理手段 | 0.4 秒，电流被切断的“咔嗒+嗡声收尾” |
| P1 | bypass.ogg | 第七幕问源绕过人类手段 | 0.8 秒，平滑的数据流转向声，冷静不吓人 |
| P2 | hover.ogg | 卡牌/按钮悬停 | 0.05 秒，极轻的 tick |
| P2 | datacenter-loop.ogg | 机房环境底噪（可选叠加） | 30 秒无缝循环，低频嗡声与风扇声 |

## 六、不要用生成模型做的

- **片尾现实新闻**：必须是真实报道，不能用 AI 生成假新闻画面或视频。现在用的是程序绘制的新闻卡片，需要人工逐条核对 `src/components/Credits.tsx` 里 5 条事件的日期和链接；如果要做视频，只能用有授权的真实素材。
- 任何真实人物的脸。
